SKETCHBOOK

3D game engine UI inspired by the Sketchbook project. GTA-style web game aesthetic with keyboard keycap controls, gold amber accent, 3D cube loader, debug panel, and SketchOS desktop.

Reference:
sketchbook-upgraded/src/css/* — Controls, Loading, Welcome Modal, Gameplay HUD, Portfolio

Design Principles

ENGINE UI

Keyboard-driven interface with physical keycap representations. Controls are always visible and accessible.

GOLD ACCENT

Amber #FFB900 with 4px shadow press effect. SweetAlert-style confirm buttons create tactile, satisfying interactions.

3D AWARE

CSS perspective cube loader, text-shadow overlays for 3D scene readability, blue gradient loading screens.
